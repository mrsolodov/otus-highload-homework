# Результаты локального стенда

23 октября 2026 года проверен вариант с четырьмя Ubuntu ВМ в VirtualBox: один балансировщик `lb` и три фронтенда `web1`, `web2`, `web3`. ВМ созданы Vagrant и настроены Ansible. Облачный вариант Terraform не запускался из-за отклонённой заявки на увеличение квот vCPU.

Скрипт `run-local-lab.ps1` завершился сообщением `Checks passed`. В переданном выводе есть следующие результаты:

| Проверка | Результат |
| --- | --- |
| Статическая страница через `/rr/` | HTTP 200, ответ от `web2`, заголовок `X-Balancing-Mode: round-robin` |
| Отключение Nginx на `web2` | Шесть запросов через балансировщик получили HTTP 200; отвечали только `web1` и `web3` |
| Восстановление Nginx на `web2` | В следующих 12 запросах HTTP 200 ответили все три фронтенда, включая `web2` |
| Удаление стенда | `vagrant destroy` вернул код 0 и сообщил об удалении `lb`, `web3`, `web2`, `web1` |

Девять ответов round-robin последовательно пришли от `web2`, `web3`, `web1`, и эта последовательность повторилась трижды. Шесть запросов с одинаковым ключом для consistent hash попали на `web3`. Полный вывод опубликован в [local-lab-run.txt](evidence/local-lab-run.txt), структурированные результаты — в [local-lab-results.json](evidence/local-lab-results.json). Из журнала удалены служебный заголовок PowerShell с именем пользователя и абсолютные локальные пути; результаты проверок сохранены.

Результаты запуска сохранены в каталоге `evidence/`.
