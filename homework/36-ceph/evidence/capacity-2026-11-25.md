# Ёмкость локального стенда — 25.11.2026

Замеры переданы пользователем из PowerShell и Proxmox Shell; команда `terraform apply` для занятия 36 не запускалась.

| Ресурс | Фактически | Требуется исходному проекту |
| --- | ---: | ---: |
| RAM физического Windows-хоста | 13,9 ГиБ всего; 2,6 ГиБ свободно при запущенном Proxmox | 12 ГиБ только для трёх Ceph-ВМ плюс Proxmox и Windows |
| RAM вложенного Proxmox | 4,8 ГиБ всего; 231 МиБ доступно | 12 ГиБ для Ceph-ВМ плюс запас Proxmox |
| `local-lvm` | 20,7 ГиБ всего; 8,9 ГиБ свободно | 120 ГиБ виртуальной ёмкости для шести дисков по 20 ГиБ |
| Уже работающие ВМ | `9101` и `9102`, по 2 ГиБ RAM и 10 ГиБ загрузочный диск | Не затрагивать при запуске нового задания |

Попытка выделить Hyper-V ВМ Proxmox 16 ГиБ RAM завершилась `OutOfMemory`; её вернули к 5 ГиБ и запустили. Уменьшение новых Ceph-ВМ до ~1–2 ГиБ не решает нехватку дискового места и опускает память ниже рекомендаций Ceph для OSD/MON/MDS. Повторные перезапуски не устранят эти ограничения. На этом ПК можно делать отдельную демонстрацию Ceph с одним узлом, но она не докажет отказоустойчивость трёхузлового кластера.

## Проверка и очистка — 25.11.2026

В `local` нет ISO и архивов (`/var/lib/vz/template/iso` и `/var/lib/vz/dump` по 4 КиБ); `/var/log` занимает 15 МиБ. В `local-lvm` находятся только системные диски и cloud-init двух работающих ВМ `9101` и `9102`. Удалять их ради занятия 36 нельзя без потери предыдущих стендов.

Во второй ВМ `otus-pve-app2` найдены семь **остановленных** Docker-контейнеров задания 33. `docker container prune --force` удалил только эти контейнеры и сообщил `1.49GB` освобождённого места. Именованные тома Vault/PostgreSQL (всего 12 томов Docker) и четыре образа остались. Запуск `fstrim -v /` на этой ВМ сообщил `2.6 GiB` обработанных свободных блоков. Использование корневой ФС ВМ уменьшилось с 7,0 до 5,6 ГиБ. Показатель свободного места `local-lvm` после TRIM пока не измерен через Proxmox.
