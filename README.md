# OTUS: Инфраструктура высоконагруженных систем

Репозиторий с практическими работами курса OTUS «Инфраструктура высоконагруженных систем».

## Правила безопасности

В репозиторий нельзя добавлять OAuth-токены, API-ключи, SSH private keys, содержимое `terraform.tfstate`, персональные данные и файлы с локальными переменными. Для входных параметров используются только безопасные примеры без секретов.

## Текущий статус

Репозиторий подготовлен. Первое техническое задание — развёртывание виртуальной машины в Yandex Cloud с помощью Terraform.
